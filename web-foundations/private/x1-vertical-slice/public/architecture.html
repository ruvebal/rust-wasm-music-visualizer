From sound to sculpture

Tidal Orrery is a kinetic sculpture driven by your recording. The mappings are Designed; feature readings are Computed. The sculpture does not simulate the physics of sound or planets.

Follow one frame

  1. The browser decodes your file. A local Blob URL gives an HTMLAudioElement access to the selected recording. There is no upload.
  2. Web Audio measures the sound. The element feeds a gain node, then an analyser, then your speakers. Gain affects what you hear and what the sculpture sees. Mute sets gain to zero.
  3. JavaScript normalizes four continuous features. RMS measures overall waveform energy. Low sums frequency-bin power from 35–250 Hz, mid from 250–2000 Hz, and high from 2–10 kHz. Each becomes a number between zero and one. The readings are relative, not calibrated decibels.
  4. A small rhythm tracker estimates tempo. src/rhythm.js compares repeated low-band rises against an adaptive baseline × thresholdFactor. It emits a bounded bpm estimate and a short beatPulse. This is an explainable onset detector, not a metronome or production-grade tempo engine.
  5. Rust smooths and maps numbers. JavaScript supplies each previous value, the new feature, and elapsed seconds. Rust returns a smooth value, then maps it into a bounded visual range. Rust owns no browser resources.
  6. Three.js renders the result. Hinges open, the core expands, materials change colour by band, and beat pulses brighten the marker and moon. A perspective camera, lit materials, depth testing and shadows make their spatial relationships visible.

Every Rust function

FunctionBeginner's explanation
unit(value)Internal guard: keep a number in 0–1. Invalid numbers become zero.
smooth(previous, input, delta_seconds, tau_seconds)Move toward the new value gently. Tau is the time to cover about 63% of the remaining distance. Using seconds makes the response comparable at different refresh rates. A frame gap is capped at 0.1 seconds.
aperture(rms)Turn energy into a hinge angle between 0.12 and 1.22 radians.
core_scale(bass)Turn bass into a scale multiplier between 0.72 and 1.30.
radiance(high)Turn high-frequency energy into emissive intensity between 0.15 and 1.25.

There is no hidden global state. Reset means setting the previous values to zero. Native Rust tests and a real Wasm test exercise the same API.

Time, silence and motion

Audio time explains the music relationship; a separate authored motion clock keeps the sculpture gently orbiting when playback is paused. Identical motion time and feature values give identical geometry. Live analyser samples can differ across browser schedules, so this is not sample-accurate synchronization. Reduced motion fixes spatial animation and retains slowly smoothed lighting.

Your student visualizer

The implemented module exports createVisualizer({ scene, THREE, features, options }). It creates one owned group and returns update({ values, time, motionTime, delta, reducedMotion }), resize({ width, height, pixelRatio }) and dispose().

export function createVisualizer({ scene, THREE, features, options }) {
  const root = new THREE.Group();
  scene.add(root);
  return {
    update({ time, motionTime, delta, reducedMotion }) {
      root.rotation.y = motionTime * 0.2 + features.mid * time * 0.1;
      // Map bass, mid, high and beatPulse deliberately.
    },
    resize() {},
    dispose() { scene.remove(root); },
  };
}

How to read this factory

  1. export function makes the module’s entry point importable by the host. The host calls this once after it has created the shared scene.
  2. { scene, THREE, features, options } is the dependency boundary. The host supplies the scene graph, the Three.js namespace, the live analysis object and optional configuration. The module does not create a second audio graph.
  3. new THREE.Group() creates the module’s ownership boundary. Every mesh, light and listener created by the module belongs under this group.
  4. update(...) runs once per animation frame. Use features for sound, time for media position, motionTime for authored continuous motion, and reducedMotion to suppress spatial animation.
  5. resize(...) is for module-specific resources such as shader resolution. The host still owns the camera and renderer size.
  6. dispose() is the cleanup promise: remove the group and release every resource created by the module exactly once.

Read the complete reference implementation in src/visualizers/tidal-orrery.js. Continue with L1 · Rust/browser boundary for the host contract, L2 · audio features for features, L3 · GPU/3D for the owned scene, and L4 · clocks and controls for time, motionTime and interaction.

  • Read the smoothed normalized features and bounded values. Modify only your group's objects and resources.
  • The host owns the scene, renderer, camera, audio, and animation loop. Do not create a second loop or audio graph.
  • Resize updates only module-specific resources such as shader resolution; the host updates the camera and canvas.
  • Dispose removes the group and frees each owned geometry, material, texture and listener once. Shared geometry must not be freed twice.

Replace the module import in src/main.js to build your own. Runtime URL plugin loading is a future extension, not a finished plugin system. If you add a moon or satellite, attach it to an intentional group or wire; never let it float as an unexplained free object. Check that the full orbit clears the plinth and floor.

Research and extension boundary

The baseline includes beat estimation so students can inspect and test the complete path. FFT is useful but not mandatory for BPM: spectral flux plus autocorrelation, wavelet envelopes, or classical DSP libraries are valid research extensions. Tune and document the threshold factor, show one false positive or missed beat, and do not describe aubio as machine learning without evidence.
